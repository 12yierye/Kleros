> Kleros 1.7 · 2026-11-07 · 一轮交互细节和动效打磨，无数据结构变更，直接替换 HTML 即可。

### ✨ 新增

- **设置项说明改为悬浮提示**：原来每项下面那行灰色说明收进标签后的 `?` 里，鼠标移上去才展开。设置界面不再被说明文字撑长，一屏能看完。
- **添加区展开 / 收缩动画**：点「＋ 添加」和「收起」时高度平滑伸缩，不再是瞬间出现消失。
- **页签切换动画**：名单添加区的 多个 / 单个 / 文件 / 从名册 切换时，内容高度平滑过渡并轻微淡入。
- **视图切换动画**：主区域的「抽取 / 名单」、侧栏的「过滤 / 参数」切换时淡入淡出，不再硬切。
- **「记住布局」改为开关**：原来是复选框，现在是一个开关，标签也从「启动时 + 沿用上次布局」合并成「记住布局」。

### 🔧 改进

- **滚动速度滑块重做**：轨道按当前值填充主色，滑块悬停放大并带一圈淡蓝色光晕，拖动时有按压反馈，键盘聚焦有双层描边。右侧读数改成胶囊样式。
- **浅色主题的按钮悬停色整体加深一档**：主按钮、普通按钮、危险按钮都更明显了；原来主按钮悬停只比常态深一点，几乎看不出来。
- **分段按钮补上悬停反馈**：主题、布局、抽取方式那几排按钮之前悬停没有任何变化。
- **选中文字的范围收窄**：按钮、页签、标题、状态栏、抽取控制条这些界面元素不可选中，名单里的人名、抽取结果、抽取记录仍然可以选中复制。
- **工具提示支持换行**：文案里写 `\n` 会真的换行，短提示仍然保持单行。

### 🐛 修复

- **按人抽时滚动动画里冒出小组名**：滚动列改按当前口径取内容——按人只滚人名，按小组只滚组名，不在任何小组里的人不会出现在按小组的滚动里。
- **工具提示里的 `\n` 不生效**：一是模板静态属性不解析转义，二是气泡的 `white-space` 会把换行折叠成空格，两处都修了。
- **开启换行后工具提示被挤成窄条**：气泡宽度改为按内容撑开，最长 260px，不再受按钮宽度限制。

### 📌 升级注意

- 本次没有数据结构和偏好的破坏性变更，直接用新的 `Kleros 1.7.html` 替换旧文件即可，名单、名册、小组、黑白名单都会照常读取。
- 设置项的说明文字从常驻改为悬停显示，第一次用可能找不到——看每个设置项标签后面的小问号。

### 🐞 已知问题

- 工具提示是纯 CSS 定位，弹窗内靠近上下边缘时可能被滚动容器裁掉一部分。
- 多音字只覆盖常见姓氏，生僻异读可能搜不到。
- 小组结果区最高 320px，抽中 4 组以上需要滚动查看。
