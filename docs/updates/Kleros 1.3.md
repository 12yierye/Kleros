### ✨ 新增功能

- **OPFS 优先的文件持久化**：切换为以 OPFS（Origin Private File System）为首选的持久化后端，自动检测并启用；不支持时降级到 `localStorage`，读取时比较时间戳以选取最新数据。  
- **JSON 文件读写支持**：新增 `useFilePersistence`，支持将名册、黑白名单、会话与偏好以 JSON 文件读写并自动同步；应用启动时自动加载并恢复状态，数据变更时自动保存。  
- **IndexedDB 升级与命名空间规范化**：数据库升级为 `kleros_v4`（版本 3），所有存储名统一加前缀 `kleros.xxx`；升级时自动创建缺失对象存储，并新增 `deleteDB` 方法用于彻底删除缓存数据库。  
- **数据库可视化查看**：新增 `DBInspectDialog` 弹窗，可实时查看 IndexedDB 各存储内容与元信息，支持刷新与复制为 JSON，设置中新增入口。  
- **历史数据兼容与分组改进**：重构默认分组规则，兼容历史数据中缺失或无效的 `groupId`，自动将旧条目归入默认分组，避免升级后出现未分组条目。

### 🔧 优化

- **持久化与读写逻辑重构**：简化并重构文件读写与初始化流程，删除文件句柄相关的冗余存储，提升兼容性与稳定性；导入/导出逻辑改为异步以提高鲁棒性。  
- **会话与恢复稳定性**：修正清空历史后自动开启新会话的问题（`clearAllHistory` -> `startNewSession`），优化会话管理初始化与恢复流程，添加调试日志以便追踪快照保存与恢复行为。  
- **性能与监控**：优化 `sessionManager` 的 `watch` 触发时机（使用 `flush: 'sync'`），在关键点打印调试信息，提高可观测性。  
- **UI 与样式简化**：简化底部文件绑定状态显示，移除可点击触发绑定的交互与相关样式，调整若干样式以匹配新持久化状态显示。  
- **工程与类型维护**：更新 `tsconfig` / 构建信息以覆盖新增文件与组件，简化 File System API 类型定义并补充新的类型声明。
