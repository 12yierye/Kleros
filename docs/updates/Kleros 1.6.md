> Kleros 1.6 · 2026-11-07 · 小组抽取的语义修正 + 一轮交互打磨，含几项行为变更，升级前看下「不兼容」一节。

### ✨ 新增

- **拼音搜索**：黑白名单、名册成员搜索支持全拼和首字母——`zs` / `zhangsan` / `ZHANG` 都能搜到「张三」，`oyzq` 能搜到「欧阳志强」。大小写不敏感，内置字典，不依赖浏览器语言环境。
- **空结果文案可配置**：没人可抽时结果区随机显示一条自定义文案。设置 → 抽取 →「调整文案」，一行一条，每次启动重新随机。
- **小组抽取按组名展示**：滚动动画和最终结果都以小组名为单位，组名下方列出成员；抽取记录显示「组名（成员）」。
- **输入面板新增「从名册」页**：标签栏变为 多个 / 单个 / 文件 / 从名册，整册加入从按钮组收进独立分页。
- **名册 / 小组独立编辑视图**：新建和编辑整块替换列表，不再在下方展开；取消与创建/保存并排放在底部。
- **弹窗体验**：设置里打开子弹窗，关闭后回到设置而不是一起关掉；名册/小组切换视图时高度平滑伸缩。

### 🔧 改进

- 抽取记录固定为 6 条的高度，条数增加不再挤压结果区。
- 新一轮（手动、自动重置、清空数据）统一清空结果区，不再残留上一轮的名字。
- 「绑定小组」在界面上统一改称「小组」。
- 名册的「整册加入」「单人加入」和名单批量的「存入名册」移除，入口收敛到输入面板。
- 几处细节：名册成员的删除按钮常显；确认框永远盖在弹窗之上；小组结果的字号放大，组名和成员层次更清楚。

### 🐛 修复

- 黑白名单选择器一滚动就关闭、筛选词丢失。
- 按小组抽整体失效：名单清空重加后小组会消失、小组人数统计不对、名额塞不下整组时一个人都抽不出。
- 黑名单的人跟着小组一起被抽中：现在黑白名单优先，组只由池内成员构成。
- 改名后成员从小群里消失：重命名会同步更新小组内的名字引用。
- 拼音搜索在部分环境静默失效：改为内置字典实现。

### ⚠️ 不兼容

1. **小组不再随名单自动解散**：清空名单后小组仍保留，重新加回同名即恢复。要删请到小组弹窗手动「拆散」。
2. **按小组抽只从小组内选人**：不在任何小组的人不参与；组内剩 1 人时也不参与。
3. **按小组抽名额可能超出**：小组不可拆，设定 2 人抽中 3 人小组就出 3 人。
4. **入口与文案变更**：名册的整册/单人加入、批量栏的存入名册已移除；输入面板「粘贴 / 手动」改为「多个 / 单个」。

### 📌 升级注意

- 升级前建议先导出 JSON 备份。
- 旧版本建的小组会自动补全成员姓名；若名单和名册里都找不到这些人，需要在小组弹窗里手动重建。
- 「按小组抽」的可抽人数现在只统计组内成员，会比名单总数小；一个组都凑不成时结果区会提示「没有可抽的小组」。

### 🐞 已知问题

- 多音字只覆盖常见姓氏，生僻异读可能搜不到。
- 小组结果区最高 320px，抽中 4 组以上需要滚动查看。
- 窗口很矮时弹窗顶到 90vh，高度动画会退化为内容淡入。
