> Kleros 1.8 · 2026-11-15 · 布局、名单归属与批量操作的一次集中整理；含几项操作方式变更，升级前看下「行为变更」与「升级注意」。

### ✨ 新增

- **纵向布局的添加弹窗**：底栏「添加」改为弹窗，粘贴 / 单个 / 文件 / 从名册都在弹窗里完成，不再把底栏临时撑高、挤走名单区。名单页与横向侧栏仍是原来的内联展开。
- **批量全选**：批量模式新增「全选 / 取消全选」，配合「删除」可以一次处理整份当前名单。
- **主视图页签键盘操作**：分页布局的「抽取 / 名单」页签支持左右方向键切换，补齐 `tab / tabpanel` 的读屏语义与焦点管理。
- **布局收起与展开**：横向布局的右侧名单栏可以收成窄条再展开；纵向布局的底栏可收起，并保留「名单 N · 展开」入口；横向布局在窗口宽度 ≤1100px 时，左侧过滤栏会自动收成图标轨，把宽度让给抽取舞台。
- **chip 归属提示**：悬停或聚焦名单 chip 时，才显示所属小组和名册。小组是「颜色小块 + 小组名」，名册是「书签图标 + 名册名」，不再常驻在 chip 上。

### 🔧 改进

- **纵向布局高度稳定**：抽取记录卡改为固定份额，记录增加只在卡内滚动，不再把舞台挤小、也不再让记录卡整体上下移动；舞台、记录卡与底栏按窗口高度流体分配，1366×768 下也不再裁切。
- **纵向底栏全宽、单行头**：底栏「当前名单」的标题与操作恢复为同一行，操作靠右；chip 列间距随屏幕宽度轻微放宽，宽屏不再只靠超长行扫读。
- **名册不再参与 chip 显色**：名册（长期保存的名单）移除颜色属性，chip 上只剩小组的彩色边框；名册归属只在 tooltip 里以书签图标出现。旧数据里遗留的名册颜色会在加载时清掉。
- **批量模式更顺手**：点击 chip 任意位置即可选中/取消；批量下不显示重命名按钮，右键重命名也关闭；复选框放在原编辑按钮的 22px 尾部位，切换批量不会改变 chip 宽度、换行或底栏高度；批量头行与复选框带短淡入。
- **弹窗视图切换更连贯**：小组、名册弹窗的列表 ↔ 编辑视图增加内容淡入；高度过渡期间隐藏纵向滚动条，不再闪入。
- **设置弹窗边缘情况**：切换「直接出现 / 滚动选择」导致折叠区展开/收起时，也不会再短暂出现滚动条。
- **交互层级修正**：Esc 先关确认框、再关普通弹窗；空格快捷键在按钮、输入框、页签等控件上不再误触抽取。
- **chip 重命名入口**：普通模式保留铅笔按钮与右键重命名；批量模式下隐藏，避免和选择操作混在一起。

### 🐛 修复

- 纵向布局抽取时，记录卡会随记录条数长高，把上方舞台挤小——现在记录卡高度固定，只在内部滚动。
- 小组 / 名册弹窗在列表 ↔ 编辑的高度动画中短暂出现滚动条；设置弹窗切换抽取样式时也有同样问题。
- 横向布局在中等窗口宽度下被左侧过滤栏挤占舞台——过滤栏现在会自动收成图标轨。
- 确认框与普通弹窗同时打开时，Esc 会先关错层。
- 小组与名册共用一套颜色标识，容易搞混——名册颜色已移除，chip 只显示小组色。

### ⚠️ 行为变更

1. **当前名单的「清空」按钮已移除**：改用「批量 → 全选 → 删除」，多一步但减少误触。
2. **名册不再有颜色**：名册弹窗不再显示色块，旧版本数据里的名册颜色会被忽略并清理；成员与分组不受影响。
3. **批量模式不再提供重命名**：批量下铅笔按钮和右键重命名都不可用，需先退出批量再改名。
4. **批量复选框位置变化**：从 chip 左侧移到右侧原编辑按钮的位置；点击 chip 任意位置仍可选中，chip 宽度与名单行数保持不变。
5. **纵向布局的「添加」改为弹窗**：如果你习惯在底栏里内联粘贴，现在会先打开弹窗；名单页与横向侧栏不受影响。

### 📌 升级注意

- 直接替换 HTML 即可，本轮没有破坏性的数据结构变更；名册的 `color` 字段会在加载 / 导入时被清掉，成员、分组和抽取记录都会照常读取。
- 如果常用「清空当前名单」，请改走「批量 → 全选 → 删除」；删除前仍有确认框。
- 横向布局在 ≤1100px 时左侧过滤栏会自动收起，可点图标轨重新展开；这是为了把宽度让给抽取舞台。
- 从旧版本导入的 JSON 里可能还带名册颜色，读取后会自动忽略，不需要手动修改文件。

### 🐞 已知问题

- 工具提示是纯 CSS 定位，弹窗内靠近上下边缘时可能被滚动容器裁掉一部分。
- 多音字只覆盖常见姓氏，生僻异读可能搜不到。
- 小组结果区最高 320px，抽中 4 组以上需要滚动查看。
- 窗口高度很低时，纵向布局的滚动列（固定 144px）与舞台内容区可能偏挤；常见 1366×768 及以上不受影响。
