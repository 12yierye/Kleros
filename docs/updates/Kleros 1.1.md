### ✨ 新增功能

- **数据导入/导出**：支持将全部数据（名单、黑白名单、会话历史、偏好）导出为 JSON 文件，并可通过导入 JSON 恢复
- **动画抽取模式**：新增「开始/暂停」抽取风格，名字在结果区快速滚动，按空格键或点击暂停揭晓结果
- **撤销操作增强**
  - ↶ 快速撤回按钮：一键撤回上一轮抽取
  - ↩ 撤销到…下拉：可选择撤销到任意一轮，并显示该轮抽取的人名
- **会话切换**：可从历史会话列表中切换回任意完整会话，恢复当时的名单与黑白名单状态
- **批量管理历史**：历史会话支持批量操作模式，可全选或勾选多个会话一次性删除
- **抽取记录展示**：主抽取区下方实时显示当前会话的完整抽取记录（时间、模式、人名）
- **按钮文本自定义**：设置中可自定义「开始抽取」和「看看是谁」按钮的显示文本
- **布局记忆开关**：新增"记住视图模式"选项，关闭则每次启动回到标签模式

### 🐛 修复

- 修正撤销按钮索引：撤销后 `pickedThisSession` 标记正确清除，被撤销的人重新进入候选池
- 修正撤销后结果展示区状态：撤销全部记录后正确回到「准备就绪」，撤销部分记录后正确显示最后一轮结果
- 修正动画期间会话切换保护：动画进行中点击切换会话不再意外中断，改为阻断并提示

### 🔧 优化

- 候选池耗尽时提示「抽完了，请回溯」并高亮撤销按钮
- 构建输出为单文件 HTML，可直接双击打开使用
